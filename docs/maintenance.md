# تعديل رحلة الجملة

الموقع المخصص لخالد حول الفعل والفاعل والمفعول به. الواجهة عربية، والتسجيلات والفيديو مدمجة في النسخة النهائية.

- المحتوى والأسئلة والتفسيرات: `content/lesson.json`.
- نصوص التسجيلات: `content/narration-manifest.json`؛ لا تربط تسجيلًا بنص مختلف عن الكلام المنطوق.
- سلوك العرض والأنشطة: `src/app.js`، والمنطق القابل للاختبار: `src/core.js`.
- التخزين: `src/storage.js`.
- الهيكل: `src/index.template.html`، والتصميم: `src/styles.css` و`src/presentation.css`.
- التجميع: `python3 scripts/prepare_media.py` ثم `python3 scripts/build.py`.
- الاختبارات: `npm test`، وفحص المتصفحات بعد تثبيت Playwright: `npm run test:browser`.

الملف `khaled-nahw-interactive.html` يضم الوسائط، ويمكن لسكربت التحضير استخراجها منه عند عدم وجود مجلد assets. بعد التجميع، انسخ الناتج كذلك إلى `index.html` إذا أردت استخدامه صفحة بداية؛ سكربت البناء يفعل ذلك تلقائيًا.

فحص GitHub Actions يقرأ المستودع، ويجهّز الناتج والاختبارات كملفات قابلة للتنزيل. لا يعدّل الفحص المستودع ولا يرفع تغييرات تلقائيًا. ارفع النسخة النهائية بعد نجاح الاختبارات. عند تعديل نص مسجّل دون تسجيل بديل، لن يُشغّل الموقع صوتًا قديمًا يخالف النص؛ سيحاول استخدام الصوت العربي بالجهاز.
