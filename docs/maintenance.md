# تعديل رحلة الجملة

الموقع المخصص لخالد حول الفعل والفاعل والمفعول به. الواجهة عربية، والتسجيلات والفيديو مدمجة في النسخة النهائية.

- المحتوى والأسئلة والتفسيرات: `content/lesson.json`.
- نصوص التسجيلات: `content/narration-manifest.json`؛ لا تربط تسجيلًا بنص مختلف عن الكلام المنطوق.
- سلوك العرض والأنشطة: `src/app.js`، والمنطق القابل للاختبار: `src/core.js`.
- التخزين: `src/storage.js`.
- الهيكل: `src/index.template.html`، والتصميم: `src/styles.css` و`src/presentation.css`.
- التجميع: `python3 scripts/prepare_media.py` ثم `python3 scripts/build.py`.
- الاختبارات: `npm test`، وفحص المتصفحات بعد تثبيت Playwright: `npm run test:browser`.

الملف `khaled-nahw-interactive.html` يضم الوسائط، ويمكن لسكربت التحضير استخراجها منه عند عدم وجود مجلد assets. بعد التجميع، انسخ الناتج كذلك إلى `index.html` إذا أردت استخدامه صفحة بداية؛ سكربت البناء يفعل ذلك تلقائيًا.

يفحص GitHub Actions المحتوى والصوت والمتصفحات، ويحتفظ بالناتج وصور التحقق كملفات قابلة للتنزيل. صلاحيات الفحص للقراءة فقط؛ ارفع النسخة النهائية بعد نجاح الاختبارات. التسجيلات المضمّنة تُنسخ كما هي دون إعادة ترميزها مع كل بناء. عند تعديل نص مسجّل دون تسجيل بديل، لن يُشغّل الموقع صوتًا قديمًا يخالف النص؛ سيحاول استخدام الصوت العربي بالجهاز.


## تفاعل السؤال والصوت

يُقرأ السؤال الجديد وخياراته تلقائيًا عند بدء التحدّي أو الانتقال إليه. يتوقف التسجيل عند اختيار إجابة، ويبقى الحل والتفسير ظاهرين. زر «اسمع الإجابة والشرح» هو الذي يشغّل الحل؛ لا تشغّله الإجابة الصحيحة أو الخاطئة تلقائيًا.

الإعدادات تفصل بين قراءة شرح المراحل، وقراءة الأسئلة، والمؤثرات القصيرة. زر السماعة العام يوقفها كلها. الرجوع إلى سؤال مُجاب لا يقرأ حله تلقائيًا.

أزرار التنقل السفلية تتبع أسئلة التحدّي أثناء نشاطه. مشاركة HTML تُظهر رابط تنزيل داخل الدرس عند غياب المشاركة الأصلية أو رفضها. إلغاء المشاركة بإرادة المستخدم لا يفرض تنزيلًا.
